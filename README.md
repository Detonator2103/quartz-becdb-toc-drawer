# quartz-toc-drawer

Мобильное оглавление для Quartz 5: на телефоне (экран до 800px) кнопка «Режим чтения» открывает
и закрывает выдвижную панель справа, как проводник слева. Панель раскрывается на весь экран
и содержит оглавление текущей страницы.

- Кнопка остаётся на своём месте и выглядит как раньше (её рисует плагин `reader-mode`).
- На телефоне у кнопки один функционал: открыть/закрыть панель оглавления.
- Панель закрывается кнопкой, клавишей Escape и нажатием на пункт оглавления.
- На ПК и планшете шире 800px ничего не меняется: режим чтения работает как обычно.
- Подсветка текущего заголовка берётся из плагина `table-of-contents` (класс `in-view`).

## Требования

Плагины `reader-mode` (кнопка) и `table-of-contents` (создаёт список заголовков) должны быть
включены. Сам этот плагин только показывает оглавление в панели.

## Установка

1. Залей папку в свой репозиторий на GitHub, например `quartz-toc-drawer`.
2. В корне проекта Quartz выполни:

   ```
   npx quartz plugin add github:ТВОЙ_НИК/quartz-toc-drawer
   ```

3. В `quartz.config.yaml` добавь блок. Позиция `left` важна: панель должна лежать в том же
   боковом блоке, что и кнопка режима чтения, иначе кнопка окажется под панелью.

   ```yaml
   - source: github:ТВОЙ_НИК/quartz-toc-drawer
     enabled: true
     layout:
       position: left
       priority: 40
   ```

4. Перезапусти `npx quartz build --serve` и открой сайт в режиме телефона (F12, Ctrl+Shift+M).

## Опции

```yaml
options:
  title: "Содержание" # заголовок панели, по умолчанию «Оглавление» (из локали сайта)
```

## Если не работает

- Панель не видна или перекрыта: у одного из предков блока может быть `transform` или `filter`,
  из-за этого `position: fixed` считается не от экрана. Проверь в F12, где лежит `.toc-drawer`.
- Кнопки режима чтения нет на мобильном: проверь, что у плагина `reader-mode` в `layout` не стоит
  `display: desktop-only`.
- На странице без заголовков панель не создаётся, и кнопка ничего не открывает.
